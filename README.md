# ⚠️ 사용 중단 — 모두의 배달은 `baedal-app` 으로 옮겼습니다

이 저장소로는 **더 이상 빌드하지 마세요.**

👉 현재 출시 저장소: **https://github.com/SeungIlJang/baedal-app**

---

## 왜 옮겼나

이 저장소는 `games/baedal.html` 을 원격에서 받아 띄우는 **Capacitor OTA 래퍼**였습니다.
게임에 아트가 들어가면서 구조적 문제가 드러났습니다.

게임이 아트를 상대경로 `assets/baedal/*.png` 로 참조하는데, 상대경로는 원격이 아니라
**앱 로컬 주소로 해석**됩니다. 이 저장소의 `www/` 에는 PNG 가 하나도 없어서 전부 404 가
나고, 아트 대신 캔버스 도형으로 폴백됐습니다. 실기에서 "디자인이 적용되지 않는다"고
보고된 현상이 이것입니다.

`baedal-app` 은 게임과 아트를 앱에 직접 번들하므로 같은 문제가 생기지 않습니다.

## 이관 완료된 것

- `STORE-LISTING.md` — Play 등록 문구
- `store-assets/` — 아이콘 512, 피처 그래픽, 스크린샷 3종

## 이 저장소를 남겨두는 이유

현재 Play 에 올라가 있는 버전(**versionCode 4 / v1.0.1**)을 빌드한 소스가 여기입니다.
라이브 버전을 되짚어야 할 때를 위해 기록으로 보존합니다.

## 다음 출시 때 주의

`baedal-app` 은 **versionCode 5 / 1.1.0** 부터 시작합니다. 그리고 패키지명이
`com.moduseries.baedal` 로 동일하므로, **서명키는 이 저장소로 출시할 때 쓰던 것과
반드시 같아야 합니다.** 다른 키로 서명하면 Play 가 업로드를 거부합니다.
